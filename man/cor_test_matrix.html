Correlation and p-value matrices of all pairs (pairwise complete observations)

Description

The engine always returns raw p-values. By default they are kept as they are (p_adjust = “none”); with another p_adjust, corrkit adjusts them with stats::p.adjust() over the k(k - 1)/2 distinct pairs, as psych::corr.test() does above its diagonal.

Usage

cor_test_matrix(
  data,
  vars,
  method = "spearman",
  p_adjust = "none",
  engine = c("auto", "psych", "correlation", "stats"),
  ci = 0.95
)

Arguments

data data frame
vars variables to correlate
method correlation method (see above)
p_adjust method of stats::p.adjust(): “none” (default, raw p-values, as in most correlation analyses), or e.g. “BH”, “holm”, “bonferroni”
engine “auto”, “psych”, “correlation” or “stats”
ci confidence level of the intervals (NULL = none)

Details

Engines (engine = “auto” picks the first available in this order):

  • Pearson / Spearman: psych::corr.test(adjust = “none”), then correlation::correlation(p_adjust = “none”), then stats::cor.test() pair by pair;

  • Kendall: correlation::correlation(), then stats::cor.test() (psych tests tau with the t formula of r, so it is not used for Kendall);

  • other methods of the correlation package (“biweight”, “percentage”, “blomqvist”, “hoeffding”, “gaussian”, “shepherd”, “distance”): correlation::correlation() only.

Binary variables are coded 0/1 (see as_cor_numeric()) and flagged in types.

Value

object of class cor_matrix: list(r, p, p_adj, n, ci_low, ci_high, long, types, method, p_adjust, engine, ci, ci_engine); long = one row per pair (i < j) with Var1, Var2, type1, type2, r, ci_low, ci_high, p, p_adj, n.

Examples

library("corrkit")

d  <- simulate_cor_data(120)
cm <- cor_test_matrix(d, c("CRP", "IL6", "BDNF", "NfL", "BIN_CRP"), method = "spearman")
